# checkup-interpretation —— 体检解读

**把历次体检报告和手表等数据交给 AI，按 Medicine 3.0 的五条读法，一个骑士一个骑士读出等级，交回一张看板和一张去问医生的问题单。**

这是一份给 AI Agent（能替人做事的 AI 助手，如 Claude Code、Codex）用的 skill（技能说明书）。你把历年体检报告的 PDF 或照片、手表和家测血压的导出交给 Agent，它照原件抄成表，沿四骑士的发病脉络读，给每个骑士定一个等级，等你确认；最后交回完整解读、一张可视化看板和按科室分组的问题单。

方法来自大鸟的健康教练 Vigil，《大鸟真人秀》No.03「体检报告回来了，用 Medicine 3.0 怎么读？」讲的就是它。上一期 No.02 的 [`checkup-planning`](../checkup-planning/) 定今年查什么；这一期读查回来的报告。

> **它是健康管理的读法，不替代医生。** 它不诊断、不开药；等级只说风险往哪边走，治疗决定和医生一起定；花不花钱再查，由你定。

## 主张：五条读法

Medicine 3.0 是医生 Peter Attia 在《Outlive》（2023，中文版《超越百岁》）里提出的医学视角：Medicine 2.0 等病确诊了再治，报告上的参考范围回答的是「你现在病了没有」；Medicine 3.0 在病形成之前几十年就动手。他要人盯住四骑士（最常把人拖垮的四种慢病），又列了 3.0 与 2.0 的五处不同。四骑士加上其中四处，落到读报告上是五条读法：

| 阿提亚的主张 | 读报告时怎么做 |
|---|---|
| 盯住四骑士，代谢是共同的根 | **顺脉络**：按代谢、心脑血管、癌症、神经退行性的顺序读，每个骑士分上游（成因）、器官证据、缓冲、下游、旁证。先看上游和器官；下游的单次值只调方向，不单独定等级 |
| 预防重于治疗 | **换尺子**：量每个值离 Medicine 3.0 的最佳线多远，不看报告箭头；参考范围内的值只当反证 |
| 你和临床试验里的平均人不同 | **看序列**：用你自己多年的数比，不盯一份报告。下游单次越线、没到诊断线，先复查 |
| 诚实评估风险，包括不做的风险 | **算总账**：贵的直接测量，等便宜的代理指标报警再做；到年龄该做的癌症筛查没做，记成缺口 |
| 病人是船长，不是乘客 | **自己拍板**：等级由你确认；带一张问题单去问医生，治疗类问题写成「我是否适合……」 |

第五处不同是寿命之外同样看重健康寿命，落在四骑士之后单列的一行体能与支撑（最大摄氧量、握力、肌肉量）：它是代谢脉络里的「缓冲」，也管后半生活得好不好。每个骑士定低、中低、中、高，或资料不够的待评估，另写证据强度强、中、弱。定级规则、指标分档与出处在 [`SKILL.md`](./SKILL.md) 和 [`references/indicators.md`](./references/indicators.md)。

文章和上一期用的几条 3.0 线（空腹血糖 75–85 mg/dL、HbA1c <5.1%、空腹胰岛素 2–6、ApoB <60 mg/dL、hs-CRP <0.5 mg/L）是更严的个人目标。本 skill 分档只用有指南或大型研究出处的线，这几条列在 `references/indicators.md` 末节，想当个人目标的可以照着管。两套线读大鸟这次的报告，五个骑士的定级相同；只有 HbA1c（5.4%）和 hs-CRP（0.7 mg/L）颜色不同：本 skill 判 🟢，按更严的线还没达到。

## 安装

先在电脑上装好 `git`。

### Claude Code

```bash
git clone https://github.com/bigbird-online/coevolution.git
mkdir -p ~/.claude/skills
cp -R coevolution/checkup-planning coevolution/checkup-interpretation ~/.claude/skills/
cd ~/.claude/skills/checkup-interpretation && ./init.sh
```

`init.sh` 准备 `user/`：同级有 `checkup-planning/` 的，把 `user/` 链到它的 `user/`，两个 skill 共用一份健康档案和抄好的报告；没有的，自建 `user/`。它再放进两份模板：`user/profile.md`（健康档案；已有的不覆盖，只在末尾补上解读要用的几栏，如身高、症状）和 `user/baseline.md`（解读结论）。之后在 Claude Code 里说「帮我读体检报告」，它会按 `SKILL.md` 的描述自动用上这个 skill。只想读报告、不要上一期的，`cp` 那行去掉 `coevolution/checkup-planning` 即可。

### 其他能读文件的 Agent（Codex 等）

```bash
git clone https://github.com/bigbird-online/coevolution.git
cd coevolution/checkup-interpretation && ./init.sh
```

然后对 Agent 说：「读 `<这个目录的完整路径>/SKILL.md`，照它读我的体检报告。」想让它以后自动用，把这句话写进你常用工作目录的 `AGENTS.md`。

### 只有网页版 AI

把 `SKILL.md`、`references/indicators.md` 全文和你的报告贴进对话。它照样能按骑士定级、写问题单，但不会替你保存抄录和结论，要你自己留着，下次一起贴进去。

## 两种用法

- **自己做**：照下文「开始用」的五步做。
- **大鸟陪着做**：大鸟远程陪你走同样的五步：装好 skill，把报告交给 AI 抄成表，读完第一个骑士、确认等级。报告和数据只放在你自己的电脑上，经过你自己的 AI 账号；大鸟看着说，不经手、不留存。

## 开始用

1. **交数据**：把历年体检报告的 PDF 或照片放进 `user/checkups/`（照上面 Claude Code 装法装的，完整路径是 `~/.claude/skills/checkup-interpretation/user/checkups/`），越全越好；手表、体脂秤、家测血压、连续血糖的导出放进 `user/wearables/`。打开 `user/profile.md`，填性别、年龄段、身高、个人史、家族史和最近的症状；不必写姓名、证件号、体检机构。
2. **抄成表**：对 Agent 说「帮我读体检报告」。它第一次往 `user/` 里写抄录时会请你授权，选允许。它先照原件逐页抄成表，同一指标排成历年一行，不用文字识别的结果；标了异常、可能改变等级的，回原件对到页码。
3. **一个骑士一个骑士读**：它先查红旗（危急值、报告写「尽快就诊」、危险症状），有就先告诉你去就医。然后从代谢读起，每个骑士讲上游、器官、缓冲、下游各落在哪，给一个建议等级。你确认了，再读下一个；你觉得不对，可以调，以你的为准。
4. **拿看板和问题单**：五个方面读完，它交回 `user/interpretation/` 里的完整解读和一张看板（HTML，用浏览器打开）：首页是全貌、最要紧的三件事和五张骑士卡，往下是各骑士的依据图。问题单按科室分组，打印带去门诊。
5. **下次报告到手**：再说一遍「帮我读体检报告」，它把新报告接进历年序列重读，等级变了会告诉你为什么。

看板长什么样，用浏览器打开 `assets/dashboard-template.html`，那是空白版式。

数据只存在本机 `user/`，不进 Git。但你和 Agent 的对话、它读到的报告，会经过你所用的 AI 服务；介意的话，先删去报告上的姓名、证件号再交给它。

## AI 读偏了，怎么拉回

AI 读得快，也会读偏。大鸟让 Vigil 给代谢定级，前两版都偏了：第一版盯着这一次的空腹血糖，定了「中」；第二版看了八年数据，却把几项多年次优的指标凑在一起，还是「中」。两次都把 3.0 抛开了，第一次丢了看序列，第二次丢了顺脉络。大鸟各回了一句，第三版按脉络分层，改成了「低」。

你也可以这样拉回：

- 它拿一份报告下结论时，说：「不要盯着一份报告，看全部历史。」
- 它把次优项凑数升级时，说：「按脉络分层：先看上游和器官，下游单次值只调方向。」
- 它建议加做昂贵的检查时，问：「哪个代理指标到了加查线？」
- 它写「你得了」「应该吃」时，说：「改成『具备……的特征』『我是否适合……』。」

`SKILL.md` 里写明了：你指出读偏，它要回到标准逐条重做这个骑士，不在原结论上修补。

## 以大鸟为例走一遍

大鸟，男，40+，不吸烟。交给 Vigil 的是 2018 年以来八次年度体检（含 2026 年这次）、一次补查、手表、14 天连续血糖和家测血压。完整解读节选在 [`examples/daniao/interpretation.md`](./examples/daniao/interpretation.md)，只用文章已公开的数值。

- **代谢：低。** 空腹血糖 102.7 mg/dL，报告没标箭头，按 3.0 的尺子越线了，而且是八次里第一次过 100。顺脉络往上游看：甘油三酯/HDL 八年都很低，五次超声没有脂肪肝，腰围 79 cm 低于 85，胰岛素抵抗指数 1.55 只略过最佳线。下游单次越线、没到诊断线 126、上游没跟着坏，所以不升级，随下次抽血复查。
- **心脑血管：中低。** ApoB 五次 66、81、71、75、82 mg/dL，报告上都在参考范围里，按 3.0 都偏高，这次最高。冠脉钙化积分 0、颈动脉没有斑块，没有器官证据；家测血压舒张压 79 贴着风险线，家族有高血压。下一步管 ApoB，恢复家测血压。
- **算总账。** 内脏脂肪定量、带胰岛素的糖耐量试验、门控冠脉钙化 CT 三项贵的检查，代理指标都没报警，或要等复查和医生算的十年风险，这次都不做。
- **癌症：中低。** 左肺下叶结节五次 5.5–7 mm，没见明显长大，报告措辞前后不一，要带全部旧片请呼吸科比片。2019 年的肠镜肠道没清干净，不算一次筛查，是缺口。
- **神经退行性、体能：低。** Vigil 的建议，大鸟还没确认。

代谢、心脑血管、癌症三个等级，都是大鸟听完一个、确认一个。去呼吸科的问题单在示例末尾。

## 升级

`user/` 不在仓库里，更新不会动它。用 `git clone` 装的，在原处 `git pull`；拷到 Claude Code 目录的，回到当初 clone 的位置执行：

```bash
cd coevolution && git pull
cp -R checkup-planning checkup-interpretation ~/.claude/skills/
```

新文件覆盖旧文件，`user/` 原样保留。
