# 健康看板

每次解读出一份，存 `user/interpretation/<最近体检日期>-health-dashboard.html`，从 `../assets/dashboard-template.html` 复制后按本文填：首页纵览在前，四骑士与体能的解析依次在后，一个文件。本人先在首页看到全貌和这个月做什么，想知道为什么再往下翻到对应的骑士。

## 首页纵览

1. **眉标**：称呼 · 日期 · 数据截至哪次体检与家测 · 确认状态。
2. **标题**：一句话说全貌，点出最要紧的骑士，如「五个方面里，心脑血管最要管：斑块已经有了」。
3. **现在最要紧的三件事**：黑底，对应完整解读的 Top 3 与一个月内的检查，每件写做什么、什么时候、为什么。
4. **骑士卡**：五张，按代谢 → 心脑血管 → 癌症 → 神经退行性 → 体能与支撑排，每张写等级胶囊（高红、中橙、中低黄、低绿、待评估灰）、证据强度、一句话依据、下一步一件事，点击跳到该骑士的解析。
5. **脉络**：一条横向流程，画上游怎样推到器官再到下游，标出本人每一层落在哪（如腰围、TG/HDL → 肝脏脂肪 → 血糖；ApoB、血压 → 斑块），让本人看到为什么先管上游。
6. **单列项与数据缺口**：单列项（如肺与呼吸）各一行，写所见与下一步；缺口一行，指向要问本人的事。

## 骑士解析

每个骑士一节，节首回链首页。从上到下：

1. **眉标**：骑士 · 确认状态（「建议，待你确认」或「本人确认 日期」）。
2. **标题**：一句话结论，等级加最主要的原因，如「代谢：低。上游不预警，要管的是腰围回升」。
3. **下一步**：黑底一条，一到三件事，先管上游。
4. **两张流程卡**：每张回答一个问题（如「内脏脂肪」「胰岛素反应」「斑块：已经长了吗」「推力：斑块的原料和压力」）。卡里依次写：直接测量是什么、什么时候才做；代理指标胶囊（✓ 正常、! 越线、? 缺口、– 未记录，各带本人值与线）；加查条件；结果（要不要加查，一句话）。
5. **主要依据**：定级和加查所依据的指标，按脉络的层与优先级排：上游、器官证据，再到下游（下游标「只调方向」）。加查条件用到的派生指标（如 TG/HDL）也放这里。每行五栏：名称加白话副标题、本次值（报告单位）、子弹图、走势小线、一句注释（历年范围、走向、要点加粗）。
6. **参考**：缓冲、旁证、标志物，以及与主要依据同一条证据的其他指标（如有 ApoB 时的 LDL-C、非 HDL-C），用小一号的行，标「不单独定级」。
7. **小注**：这一节的数据来源与时间范围、Medicine 3.0 线和 Medicine 2.0 线的出处、加查线是本 skill 的建议。

全页末尾放一次总脚注：等级与证据强度的含义、「本图用于健康管理参考，不是医疗诊断」。

## 子弹图

- 线名写全，不用「3.0」「2.0」这样的简称。
- Medicine 3.0 最佳区：绿色浅底加绿色实线。
- Medicine 2.0 线：灰色虚线，取报告参考上限或诊断阈值。
- 加查线：橙色倒三角。
- 本次：蓝色实心点；历年：灰色空心点；家测均值：蓝色空心菱形。
- 线名和线的数值标在线段上方，一律写成「线名 数值」，如「Medicine 3.0 线 70」「Medicine 2.0 线 85」「加查线 80」；几条线落在同一个值时用顿号合并，如「Medicine 3.0 线、加查线 1.50」。不用「·」「/」等符号。靠得近的错开成两行。轴两端的刻度标在下方，和线名不挨着。
- 没有 Medicine 2.0 线的（如 TG/HDL）不画，在小注说明。图例放在主要依据标题下。

## 癌症

流程卡改为「风险因素」和「筛查：直接看」。主要依据放两样：每个要随访的所见一行，画历次大小（按 `indicators.md`「所见怎么判断」取平均径或最大径，线为 6 mm、8 mm 等随访分档），行尾写类型、增长与否、恶性概率（有的）和所落的档，不照抄报告措辞；按部位的筛查日历（行是部位，列是历次体检，圆点分查了正常、有发现要随访、良性所见、没做；行尾色条红为缺口、橙为随访、绿为到位，并写一句状态）。肿瘤标志物放参考区，只画报告参考上限。

## 待评估

流程卡写缺什么、怎么补（问本人、下次体检加项、手表读数），主要依据只放已有的上游数据，不画空子弹图。神经退行性的参考推算（心脑血管、代谢两骑士的等级）每行画等级胶囊加一句依据，标「参考推算」，不画子弹图；等级胶囊与骑士卡只写「待评估」。

## 写法

- 缩写和术语首次出现带白话，如「非 HDL-C：总胆固醇减 HDL（好胆固醇），所有坏颗粒装的胆固醇」。
- 数字取原件，均值不取整判档；看板与完整解读的数字一致。
- 首页只放结论和行动；数字放各骑士的解析里，每节只讲一个骑士，不放与等级和下一步无关的数。

## 渲染

HTML 自包含：内联 CSS 与 SVG，不引外部字体、脚本和图片；首页与各节之间用页内锚点跳转。页宽固定 1000 px（子弹图要横向空间），手机上整页缩放看。能截图时用无头浏览器截首页与各节（2 倍清晰度），发 PNG 与 HTML；截不了就发 HTML，并说明没看到渲染效果。
