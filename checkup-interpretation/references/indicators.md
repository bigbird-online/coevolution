# 指标分档与出处

按骑士顺序排，表内按发展脉络的层排（层的含义见 `SKILL.md`「四骑士的发展脉络」）。🟢 最佳、🟡 次优、🔴 风险；标「本 skill 取值」的档没有指南直接给出，是按所列研究定的，证据弱于指南档。表外指标只用报告参考范围和本人趋势。

- 区间 a–b 指 ≥a 且 <b；各档首尾相接，不留空档，按换算后的连续数值判档，不取整。
- 表里写明安全下界或上界的（如空腹血糖 <70、维生素 D ≥100），越界的值归 🔴，不进 🟢，也不当保护因素。实验室的异常标志另记，不自动改分档；表里没写安全界、值又超出实验室范围的，写进脉络判断并提示复查或问医生，不自动判红（如按医嘱降脂后 LDL-C 低于实验室下限）。
- Medicine 3.0 线是 🟢 档的边界，取风险最低的那段：大型队列或随机试验里风险开始上升的点，不取「还没得病」的诊断线或正常上限。Medicine 2.0 线取报告参考范围的边界，报告没有时取表中所列的诊断线。看板上两条线都画。
- 分档只用来判断风险，不是个人目标。个人目标以医生定的为准；医生没定时，🟢 档只作一般参考，并列为就诊讨论项。

## 单位换算

| 指标 | 换成标准单位 |
|---|---|
| 葡萄糖 | mmol/L × 18.02 = mg/dL |
| 总胆固醇、LDL-C、HDL-C、非 HDL-C | mmol/L × 38.67 = mg/dL |
| 甘油三酯 | mmol/L × 88.57 = mg/dL |
| TG/HDL 比值 | 用 mmol/L 算出的比值 × 2.29 = 用 mg/dL 算出的比值 |
| 尿酸 | μmol/L ÷ 59.48 = mg/dL |
| 肌酐 | μmol/L ÷ 88.4 = mg/dL |
| ApoB | g/L × 100 = mg/dL |
| Lp(a) | mg/L ÷ 10 = mg/dL；nmol/L 与 mg/dL 之间没有固定系数，照报告单位用对应切点，不互换 |
| 空腹胰岛素 | pmol/L ÷ 6.0 = μIU/mL |
| HbA1c | IFCC mmol/mol ÷ 10.929 + 2.15 = % |
| 25-羟维生素 D | nmol/L ÷ 2.496 = ng/mL |

## 3 癌症

没有最佳区间，也没有可靠的代理指标，只做筛查分层：到年龄该做的筛查本身就是直接测量，没做是缺口。肿瘤标志物异常不调整定级。结节随访做完和常规筛查做完分开判断：结节按期复查，不等于这个部位的常规筛查已完成。以下条件只适用于无症状、平均风险的人；有症状、癌前病变史、相关疾病史或家族史的，方案由医生定。

| 部位 | 已排除的条件 | 出处 |
|---|---|---|
| 结直肠 | 45 岁起，按本人采用的一种策略：肠镜正常（10 年内有效）；或 FIT（粪便免疫化学检测，报告写「免疫法」或以 ng/mL、μg/g 给定量值）或高敏感愈创木脂法便隐血每年阴性；或医生采用的其他 USPSTF 认可策略按其周期。做了哪一种就算采用了哪一种。方法或敏感度不明的普通便隐血不算完成筛查。粪便检测阳性必须做肠镜，阳性未做肠镜记为缺口 | USPSTF 2021 |
| 宫颈 | 21–29 岁：细胞学阴性（3 年内有效）。30–65 岁按本人采用的一种策略：细胞学阴性（3 年内有效）；高危 HPV 单检阴性（5 年内有效）；HPV 与细胞学联合检测双阴（5 年内有效） | USPSTF 2018 |
| 乳腺 | 40–74 岁：按和乳腺外科定下的方式与周期做了常规筛查（USPSTF 2024：乳腺 X 线每两年一次；中国指南以超声为主，致密型乳腺可联合 X 线），结果 BI-RADS 1–2。每年做乳腺超声并有 BI-RADS 分类的，算方式已定；方式没定的记为缺口。已有所见按下节「所见怎么判断」 | USPSTF 2024；中国女性乳腺癌筛查指南 |

### 所见怎么判断

肺结节、乳腺结节、甲状腺结节都很常见，绝大多数是良性。判断看测得的特征、增长和按最新指南估的恶性概率，不看报告的措辞：「多系炎性」「良性可能」不降档，「建议复查」「形态欠规则」不升档。报告的话只用在两处：明确提示恶性可能的，按红旗就医；写了复查间隔的，作排期参考。

1. **抄特征**：每个要随访的所见写部位、大小、类型（肺：实性、部分实性、磨玻璃）、边缘、良性特征、同类所见的个数、首见日期。大小取长径与短径的均值（平均径）；报告只给一个数或一个范围的，取最大径，并注明。毛刺要报告明确写出才算有；没写边缘的按没有；写了「欠规则」「分叶」「边缘不清」的算未确认，请影像科复读。良性特征：肺结节的弥漫、中央、层状或爆米花样钙化，含脂肪，紧贴叶间裂或胸膜的三角形、扁豆形结节。
2. **认同一个**：按部位、层面编号和大小把历次的所见对上。
3. **判增长**：同一所见平均径增大 ≥2 mm，或亚实性结节出现、增大实性成分，算增大；不到 2 mm 在测量误差内，不同机构、不同医生量的尤其如此。没比片前，比同一器官旧报告的最大径大 ≥2 mm，或以前没有、这次出现的，按新发算；大小没变、只是位置写法对不上的，标「待比片」。
4. **估恶性概率**：
   - 肺：≥8 mm 的结节用 Brock 模型（PanCan 全模型含毛刺；BTS 2015 用于 ≥8 mm）分档；<8 mm 的按大小与增长分档，Brock 只作参考。对数几率 = 0.0287×(年龄−62) + 女性 0.6011 + 肺癌家族史 0.2961 + 肺气肿 0.2953 − 5.3854×[(平均径 mm/10)^−0.5 − 1.58113883] + 类型（实性 0，部分实性 0.377，磨玻璃 −0.1276） + 上叶 0.6581 − 0.0824×(结节个数−4) + 毛刺 0.7729 − 6.7892；概率 = e^对数几率 ÷ (1 + e^对数几率)。结节本身没写清的取较高的一边：类型不明按部分实性，部位不明按上叶，报告写「多发」「散在」而没给数的按 2 个，毛刺未确认的两种都算、取较高。肺癌家族史、肺气肿按个人史与报告取，不知道的按没有，列进「待问」。模型来自西方吸烟筛查人群，用在不吸烟的中国人身上是近似值，只用来分档，不当诊断告诉本人。
   - 乳腺：BI-RADS 3 ≤2%，4A 2–10%，4B 10–50%，4C 50–95%，5 ≥95%。
   - 甲状腺：ACR TI-RADS 1–5 级约 0.3%、1.5%、4.8%、9.1%、35%。不必随访的线：3 级 <1.5 cm、4 级 <1.0 cm、5 级 <0.5 cm；穿刺线：3 级 ≥2.5 cm、4 级 ≥1.5 cm、5 级 ≥1.0 cm；两线之间的要随访。报告没写分级的，下次彩超请医生写上。
5. **判稳定**：同一所见从最早可比的检查起没增大，实性肺结节满两年、亚实性或类型不明的肺结节满五年、BI-RADS 3 满两年、要随访的甲状腺结节满五年，按良性所见看。跨机构的数字要请影像科或呼吸科对比原片确认；同一份报告写明「与某次比较未变」的，可作依据。

每个所见按下表定一档，骑士取所有所见与癌前病变史中最高的一档。先看「不必随访」：落在其中的所见，新旧都定低，不再往上对。

| 档 | 条件（满足任一） |
|---|---|
| 不必随访 → 低 | 低危者的实性肺结节 <6 mm（单个或多发）；有良性特征；BI-RADS 1–2；TI-RADS 1–2 级，或 3–5 级在不必随访的线以下 |
| 高 | 恶性概率 ≥10%（BTS 2015：≥8 mm 的肺结节 ≥10% 建议 PET-CT 或活检）；BI-RADS 4–5；甲状腺结节达到穿刺线；报告明确提示恶性可能 |
| 中 | 新发或增大；≥8 mm 的肺结节恶性概率 5–10%；毛刺已确认；癌前病变史（结直肠腺瘤、萎缩性胃炎伴肠化或异型增生、宫颈 CIN2 及以上） |
| 中低 | 没有增大、还在随访期内（BI-RADS 3 未满两年；肺结节 ≥6 mm 未过稳定期；要随访的甲状腺结节未满五年；未分级的甲状腺结节；待比片的） |
| 低 | 已过稳定期 |

随访间隔：偶发实性肺结节，单个 6–8 mm 于 6–12 个月复查 CT，>8 mm 于 3 个月复查或做 PET-CT、活检；多发最大 6–8 mm 于 3–6 个月复查；亚实性 ≥6 mm 按 Fleischner 分型定；BI-RADS 3 约 6 个月复查。最终间隔由呼吸科、乳腺外科、甲状腺外科定；报告与医生都没给间隔前，To-Check 写一个月内看对应专科。

出处：McWilliams 2013 NEJM（Brock 模型）；Fleischner 2017；BTS 2015；ACR BI-RADS 第 5 版；ACR TI-RADS 2017。

## 不作标准的观点

这些数值比上表更严，来自个人观点、专家的经验目标或无出处的旧规则，没有指南或大型研究直接给出：尿酸 <5 mg/dL（Attia 书中病例）、空腹血糖 75–85 mg/dL、HbA1c <5.1%、空腹胰岛素 2–6 μIU/mL、ApoB <60 mg/dL、hs-CRP <0.5 mg/L、GGT <16 U/L、同型半胱氨酸 <8 μmol/L。本人想把它们当个人目标的，可以介绍，标明是观点；分档、定级只用上表。
