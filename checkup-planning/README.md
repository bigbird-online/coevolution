# checkup-planning —— 年度检查规划

**按 Medicine 3.0 的四骑士，定你每年该做哪些检查、这次体检加哪些项目，并记着到期的复查。**

这是一份给 AI Agent（能替人做事的 AI 助手，如 Claude Code、Codex）用的 skill（技能说明书）。你把体检套餐表发给 Agent，它读你的健康档案，交回一张分好组、每项写明理由的单子；报告到手，它照原件抄录，更新你的年度检查对照；哪项检查到期了，它会提醒你。

方法来自大鸟的健康教练 Vigil，《AI真人秀》No.02「体检报告全是『正常』，就等于健康吗？」讲的就是它。

> **它是方法与提醒工具，不替代医生。** 它不诊断、不开药；影像判读、用药和内镜交给医生；做不做、花不花钱由你定。

## 主张：Medicine 3.0 与四骑士

Medicine 3.0 是医生 Peter Attia 在《Outlive》（2023，中文版《超越百岁》）里提出的医学视角。他把今天医院里的主流医学叫作 Medicine 2.0：等病确诊了再治；Medicine 3.0 在病形成之前就找风险、早干预，目标是健康寿命，不只是寿命。落到体检上是三条：

- **早查、按个人查。** 慢病要几十年才成形，等化验单上出现箭头已经晚了。报告上的参考范围是按人群划的，判断要对照你自己的历年数据和最佳值。
- **盯住四骑士。** 人到中年后，多数人死于四类慢病：代谢失调、心脑血管病、癌症、神经退行性病。年度检查就是逐一给这四类找缺口。
- **只做能改变决定的检查。** 做了能改变判断、改变行动的，叫分水岭检查；查了不改变任何决定的，不查。

四骑士按代谢、心脑血管、癌症、神经退行性的顺序排，检查清单照这个顺序列。预算不够时，先保到期的复查、医生已安排的检查和按个人史该做的筛查，不论属于哪个骑士；其余可选项目再照这个顺序从后往前删。代谢排第一，因为胰岛素抵抗、脂肪肝、内脏脂肪会同时抬高另外三类病的风险，它最早出现，也最容易逆转。完整的年度清单与选项规则在 [`SKILL.md`](./SKILL.md)。

## 安装

先在电脑上装好 `git`；提醒脚本要 `python3`（3.8 以上，macOS 和多数 Linux 自带），没有也能用，只是少了命令行提醒。

### Claude Code

```bash
git clone https://github.com/bigbird-online/coevolution.git
mkdir -p ~/.claude/skills
cp -R coevolution/checkup-planning ~/.claude/skills/
cd ~/.claude/skills/checkup-planning && ./init.sh
```

`init.sh` 在 skill 目录下建 `user/`，放进两份空模板：`user/profile.md`（健康档案）和 `user/checkup-tracker.md`（年度检查对照），已有的不覆盖。之后在 Claude Code 里说「我下个月体检，这是套餐表，帮我挑项目」，它会按 `SKILL.md` 的描述自动用上这个 skill。

### 其他能读文件的 Agent（Codex 等）

```bash
git clone https://github.com/bigbird-online/coevolution.git
cd coevolution/checkup-planning && ./init.sh
```

然后对 Agent 说：「读 `<这个目录的完整路径>/SKILL.md`，照它帮我规划体检。」想让它以后自动用，把这句话写进你常用工作目录的 `AGENTS.md`。

### 只有网页版 AI

把 `SKILL.md` 全文和你填好的 `assets/profile.template.md` 贴进对话。它照样能出单子，但不会替你保存对照表，对照表要你自己留着，下次一起贴进去。

## 先看示例

不填任何东西，先看大鸟的对照表会提醒什么（在 skill 目录下）：

```bash
python3 scripts/due.py examples/daniao/checkup-tracker.md --today 2026-11-10
```

会打印 4 项「60 天内到期」：2026 年度体检报告、左肺下叶结节、肠镜、胃镜；另列 2 项「等报告」：冠脉钙化积分、APOE。

## 开始用

1. 打开 `user/profile.md`，填性别、年龄段、个人史和家族史。不必写姓名、生日、住址、电话、证件号；不确定的空着，Agent 会问。
2. 把体检套餐或自选项目表（截图、PDF 都行）发给 Agent，说「帮我挑项目」。
3. 你定了，让它记进 `user/checkup-tracker.md`。报告出来后把原件发给它，让它照原件抄录。
4. 随时问「还有什么检查到期了」，或跑 `python3 scripts/due.py`。

数据只存在本机 `user/`，不进 Git。但你和 Agent 的对话、它读到的文件，会经过你所用的 AI 服务。

## 以大鸟为例走一遍

大鸟，男，45–49 岁，不吸烟。档案里和挑检查有关的：幽门螺杆菌阳性已根除；左肺下叶有个小结节，三年没长大，在随访；没有甲状腺结节；肠镜、胃镜都没做过。他的档案与对照表在 [`examples/daniao/`](./examples/daniao/)（只含大鸟本人的健康数据与家族史的病名，已去掉姓名、精确年龄、住址、通讯方式、证件号、就诊机构与具体日期）。

**他发来的**：2026 年度体检的 12 项自选项目——胸部 CT、血脂四项、载脂蛋白 B、糖化血红蛋白、胰岛素、颈动脉彩超、超敏 C 反应蛋白、腹部彩超、便隐血、总 PSA、同型半胱氨酸、前列腺彩超。

**按本 skill 走一遍交回的单子**（演示，不是医嘱；示例不公开序号与价格，真用时每项会写序号、价格，末尾写合计与剩余额度）：

已选
- 代谢｜糖化血红蛋白：年度清单每年项；2023–2024 年逐年上升。
- 代谢｜胰岛素：算胰岛素抵抗指数 HOMA-IR 要它，必须和空腹血糖同一管血。
- 代谢｜腹部彩超：年度清单每年项，看有没有脂肪肝。
- 心脑血管｜血脂四项、载脂蛋白 B：ApoB 是分水岭检查；补测 75 mg/dL，高于 3.0 最佳的 60。
- 心脑血管｜超敏 C 反应蛋白：年度清单每年项；补测 1.30 mg/L，3.0 最佳是低于 0.5。
- 心脑血管｜颈动脉彩超：年度清单里按年龄、个人史定的心脑血管项。
- 癌症｜胸部 CT：已有肺结节，随访要带旧片对比。
- 癌症｜便隐血：年度清单每年项。
- 癌症｜总 PSA、前列腺彩超：年度清单里男性该做的项；PSA 2024 年没测。
- 神经退行性｜同型半胱氨酸：年度清单每年项；补测 10.9 μmol/L，3.0 最佳是低于 8。

建议加
- 代谢｜空腹血糖：和胰岛素同一管血，才算得出同日 HOMA-IR，这是代谢的分水岭检查。
- 代谢｜TSH：年度清单每年项，2023 年以后没测过。

看情况加
- 代谢｜肝脏脂肪定量：腹部彩超提示脂肪肝才加。
- 心脑血管｜冠脉钙化积分：分水岭检查，符合条件时做。大鸟是男性、45–49 岁，过了起查年龄；档案里还没有十年风险，要先评估出来，落在边缘或中等、结果会影响要不要用他汀，才做。不在这个范围而本人想做的，写下理由，和医生讨论。项目表上没有，符合条件时到场问能不能做门控 CT 出 Agatston 积分，做不了就另约。
- 神经退行性｜APOE：可选项，不算缺项。测前先说清：结果不能预测是否得病，不改变每个人都该做的预防，阳性可能带来心理负担，也牵涉血亲；建议先和医生或遗传咨询谈。本人知情后决定要测，才列进单子。
- 体能与支撑｜眼压与眼底：40 岁后该查，基础项目里有就不必加。

免费基础项目
- 代谢｜尿酸、肝功（含 GGT）、肾功（肌酐、eGFR）、腰围与体成分；心脑血管｜血压。逐项核对原表，基础项目里没有的移到「建议加」。

表上没有，要到场问或另约
- 癌症｜肠镜：45 岁起该做，没做过，分水岭检查；另约，和胃镜同次。
- 癌症｜胃镜：40 岁后有幽门螺杆菌史。
- 癌症｜呼吸科门诊：CT 出来后，按呼吸科定结节随访。

这次不加
- 心脑血管｜Lp(a)：一生测一次，2023 年已测，94 mg/L。
- 癌症｜甲状腺彩超：没有甲状腺结节。
- 体能与支撑｜最大摄氧量、肌肉量、握力：不靠体检。最大摄氧量取手表的估计值，肌肉量取体脂秤的估计值；握力用握力计另测，没测过记「未知」。
- 肿瘤标志物全套、血流变、心肌酶：既不是分水岭检查，也不是在追信号的复查。

体检当天：空腹、憋尿；问 CT 是否低剂量、要电子影像；符合条件的话，问前台冠脉钙化积分能不能做。

**之后**：大鸟知情后决定冠脉钙化积分和 APOE 都做；项目表上没有，2026 年度体检当天加做了，报告待出。定稿项目、当天加做的两项、要另约的肠镜和胃镜，都记进了对照表（[`examples/daniao/checkup-tracker.md`](./examples/daniao/checkup-tracker.md)），每行写了「到期」，报告未出的两项写「待报告」。上面「先看示例」那条命令列出的 4 项到期和 2 项等报告，就是从这里读出来的。

## 定时提醒（可选）

每次你用这个 skill，Agent 会先告诉你什么到期了。想不打开 Agent 也有一份到期清单，就让电脑定时跑 `scripts/due.py`。下面这行每月 1 日早上 9 点把清单追加到 `user/reminders.txt`，你打开这个文件就能看到；要弹通知或发消息，把这条命令接到你常用的通知工具上（把路径换成你自己的 skill 目录）：

```bash
crontab -e
# 加这一行：
0 9 1 * * cd ~/.claude/skills/checkup-planning && python3 scripts/due.py >> user/reminders.txt 2>&1
```

提前多少天提醒用 `--days` 改，默认 60。

## 升级

`user/` 不在仓库里，更新不会动它。用 `git clone` 装的，在原处 `git pull`；拷到 Claude Code 目录的，回到当初 clone 的位置执行：

```bash
cd coevolution && git pull
cp -R checkup-planning ~/.claude/skills/
```

新文件覆盖旧文件，`user/` 原样保留。

## 目录一览

```
SKILL.md                   方法、选项规则、年度清单、流程、抄录规矩（Agent 读）
init.sh                    建 user/，拷模板；可重复运行，不覆盖
scripts/due.py             列出已过期和快到期的检查（只用 Python 标准库；--self-test 自检）
assets/                    两份模板：健康档案、年度检查对照
examples/daniao/           大鸟的示例档案与对照表
user/                      你的档案、对照表、抄录的报告——不入库
```
