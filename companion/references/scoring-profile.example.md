# 领域插件示例 —— 某位会员反传积累出来的评分加权（示例样本，非默认配置）

> ## ⚠️ 读这份文件前先读这三条
>
> 1. **这是示例，不是默认值。** 下面每一条加权、每一个封顶阈值，都是**某一位具体会员**在数十次实测反传后长出来的。它们对那位会员成立，对你不成立。
> 2. **init 不拷贝本文件。** 产品内核初始化时不会把这里的任何规则装进 `user/`。你的实例从**空**起——没有任何继承来的加权。
> 3. **照抄别人的口味是错误用法。** 这份文件的价值在**形态**不在**数值**：它示范了「一条 per-member 加权长什么样、需要几个实测样本才够立、怎么写可证伪锚防止自己过拟合」。看完请把它合上，去积累你自己会员的那一份。
>
> 用法：把它当**范本**读一遍，然后在 `user/` 下从零建你自己的加权段。每加一条，都要能答出「哪几次实测把它逼出来的」——答不出就还不该立。

---

## 这份示例包含什么

| 段 | 内容 | 为什么它是 per-member 的 |
|----|------|--------------------------|
| 一 | 用户特征加权表（文体偏好 / 思考引发 / 关注人名册） | 每一行的方向和幅度都来自这位会员的实测反传，换个人方向可能相反 |
| 二 | 生命健康域子规则（锚定一本特定的健康观著作） | 整段绑定「这位会员认哪套健康观」，换个会员可能锚完全不同的书、甚至没有健康域 |

两段都是**领域插件**：产品内核（`references/scoring.md`）里的通用机制（文体上限 / 论证硬度门 / 会员先验增量门 / actionability 硬门 / 触达差价）不依赖它们照样跑。插件只做「在通用尺子上再叠一层这位会员特有的口味」。

## 一、用户特征加权（per-member tuning，反传积累）

> 示例会员实测得出的加权规则。**其他会员复用时应把本段整体重置为空**，从零积累自己的。

| 加权规则 | 方向 | 幅度 | 依据 |
|---------|------|------|------|
| 调查体 / 事实驱动型（记者不下结论、多方信源、具体数据） | 内容分 +0.5 | 某次实测 7.5 | 该会员主动表扬"作者的写法我很喜欢——没有观点，只有陈述"；保守派会主动调动世界观消化事实，但对预设结论的文章快速反弹 |
| 观点体 · **立场表态型**（作者给的是不可证伪的立场/价值判断/党派预设结论） | 内容分 -0.5 | — | 同上的反向；该会员对"预设结论"快速反弹 |
| 观点体 · **作用层可证伪型**（作者下的是**可被后续数据证伪**的判断/call，且给出验证点，如宏观分析师那类"X 会发生，看 Y 验证"的 call） | **不扣**（-0） | 产能盘点结论 + 两次误伤实证 | **下可证伪 call 是这类分析师的价值不是立场**——他给"X 会发生，看 Y 验证"，读者能拿走一把可检验的尺；与"立场表态型"（给不可证伪的价值判断）本质不同（与内核尺子 §智识诚实检验的分野一致：作用层派 vs 解释派）。**防滥用**：仅当判断**真可证伪**（有明确的可观测验证点/时间点）才豁免；把"我认为该更强硬""这是错的政策"这类不可证伪立场包装成 call 的，仍按立场表态型 -0.5。actionability 硬门/三元规则/论证硬度门照常全扣，本豁免只免"观点体 -0.5"这一项。 |
| 思考引发加分（thinking_meeting_bonus） | 内容分 +0.5 | 上限 +0.5 | 某篇实测 7.5（base 7.0 + 0.5）。会员明示"打 7.5 实际 7.0，但它引发我的思考和会议，增加 0.5"。**判据硬约束**：（1）必须由会员显式说明"引发思考/会议/认知整理"，评分方不自评（防自评跑偏）；（2）伴读必须确实产生连续多轮深度对话（≥3 轮往返推进）；（3）加分独立于素材分，**不与三元规则/会员先验增量门/论证硬度门抵消**——那几条是评素材，这条是评"素材引发会员思考的乘数效应"。**防滥用**：单次最多 +0.5；不允许多次叠加；若会员同 session 评 ≥3 篇均加此项，触发 audit（可能是伴读方过度引导）。 |
| 关注人名册作者加权（hero_watchlist_bonus） | 内容分 +0.3 | 上限 +0.3 | 重建「关注人」选文角度时立。源带 `hero-watchlist` tag 的作者文章 +0.3。**作用 = 同等质量下个人作者略优先于机构文**，不是"因为是名人所以加分"。**关键约束（防误读成放行）**：①**不豁免任何质量审查**——三元规则/会员先验增量门/论证硬度门/actionability 硬门/文体上限照常全扣；平庸的名家文照样过不了 8.0，单篇分仍凭素材挣。②与"机构立场不加分"（三元规则#3）对称：那条压机构，这条微抬个人作者，方向一致=救回被机构稀释的"关注人"角度。③+0.3 是温和值不是 +0.5/+1.0——避免重蹈评分尺一直在防的"权威/框架感虚高"。详见下方说明块。 |

### hero_watchlist_bonus 判定硬步骤 + 设计说明

**判定步骤**（关② 之后、min 上限之前）：
1. 查候选 `source` 对应 sources.yaml 条目的 `tags` 是否含 `hero-watchlist`
2. 含 → final 内容分 +0.3，记 `score_breakdown.hero_watchlist_bonus: 0.3` + 命中作者名
3. 不含 → 不动

**⚠️ +0.3 触门自检（经一次 both-fail 复盘裁定后加）**：当 `base + hero(+0.3)` 恰好跨过 8.0（即**扣掉 +0.3 就不过门**）时，**不许用 +0.3 当过门器**——回到 base 重审是否漏扣确认型。hero +0.3 的设计意图是"同等质量下名家文略优先"，不是"把 7.7 的文顶成 8.0"。触发样本：某篇经济评论评分方判 base 7.7 + hero 0.3 ≈ 8.0 过门；独立复核发现评分方**漏扣前半段确认型 -0.3**（该会员每日经营多 Agent 组织、反馈日志早已内化"超带宽任务外包给 Agent"，该文前半"AI→更多外包→个体创业者"对他=确认型），扣回后 base 7.5 − 0.3 + 0.3 − 0.5(校准) = **7.3 不过门**。**下次行为**：base+hero 卡在 8.0 门上时，先把 hero 那 +0.3 遮住看 base 过不过；base 不过 8.0 而只靠 +0.3 顶过 = 判"平庸名家文硬顶"，回 base 补审确认型，凭素材挣不到 8.0 就不推。

**为什么是 +0.3 而非更高 / 为什么不豁免审查**：
- "关注人"角度被"关注机构"一轮轮补源稀释（旧的作者名单是死文件无人读），要把它救回来。
- 但评分尺整套精神是**反虚高、反框架感、反机构立场**（三元规则#3、论证硬度门都在防"因为谁说的就给高分"）。顶级作者值得追是因为**持续产出好素材**，不是名字本身能让平庸文章变好——会员最初立名册时就定"地位不是入选理由"。
- 所以加权必须温和（+0.3）且**绝不豁免质量审查**：让名家文在同等质量下略优先，但单篇分仍凭素材挣。把 bonus 调大或允许豁免 = 把评分尺一直在防的东西引回来。

**待观察（采集层配额的触发信号）**：
- 机构立场在评分里**已经被压**（三元#3 不加分 + avoid 源门槛 8.5）。若跑几天发现名家文仍被机构"量"淹没（机构源发文勤、占满候选池，名家文在关⓪预筛阶段就被挤掉），说明真问题在**采集层的量**不在打分的分——届时上**采集层配额**（限机构源每轮进池数，给 hero-watchlist 源留位），而非继续抬 bonus。
- 监控指标：reading-log 里 hero-watchlist 源的 selected 占比 vs 机构源 selected 占比；连续低 = 触发采集层配额评估。

## 二、生命健康域子规则（示例：锚定某本特定健康观著作）

> **这一整段是最典型的「领域插件」**：它把某位会员认可的一套健康观（一本系统读过的著作 + 其"预防医学"范式）当成该域的评分锚。**换个会员，这个锚可能是另一本书、另一套范式，或者根本没有健康域。** 照抄本段 = 把别人的健康观塞进你的会员的尺子里。
>
> **触发场景**：candidate.domain == "health" 或文章主题命中下述五杠杆/四骑士。
> **怎么长出来的**：一次干细胞疗法类文章被推送后，会员反传"依赖救世主=奴役 / 泛医疗事故规模 / 真解是每个人为自己负责"→ 由此明确锚定这套预防医学框架。
> **profile.yaml 同步**：focus_domain 生命健康子轴改为"前置健康（锚：该著作）"+ score_baseline 生命健康域专用门。

### 锚结构（用于命中加分判定）

**四骑士**（前置预防优先级）：
1. ASCVD（动脉硬化心血管病）：核心指标 ApoB / Lp(a) / hsCRP / 血压
2. 癌症：早筛 / 大肠镜起始年龄 / 全身 MRI 争议
3. 神经退行性疾病：脑代谢 / Omega-3 / 听力保护 / 睡眠
4. T2D 代谢紊乱：HOMA-IR / 空腹胰岛素 / CGM 数据 / 餐后葡萄糖曲线

**五大杠杆**（actionability 命中点）：
1. Exercise（该框架视为最强单一杠杆）：Zone 2（线粒体）/ VO2max（全因死亡率最强预测）/ 抗阻（肌少症 + 骨密度）/ 稳定性（防摔）
2. Nutrition：蛋白质剂量（≥1.6g/kg）/ 优质蛋白来源 / 限时进食窗口 / 热量平衡
3. Sleep：时长（7-9h）/ 时相 / 睡眠呼吸暂停筛查 / 昼夜节律
4. 情绪健康（原作者自述这是他最难/最重要的杠杆）
5. 外因：酒精减量 / 戒烟 / 激素优化

### 评分加减分规则

**前置加分**（可叠加，上限 +1.5）：
- 命中四骑士某项的前置数据/检测/指标（含上述生物标志物或新发现的）→ **+0.5**
- 命中五大杠杆某条的 RCT / meta-analysis 一手证据（含蛋白质剂量、抗阻剂量、进食窗口、桑拿剂量、睡眠时相等）→ **+0.5**
- 对既有主张的关键证伪（新研究推翻原阈值/原指标/原剂量）→ **+0.5**

**封顶判定**：
- 事后医疗向（病已发 + 反伪科学打假 + 政策呼吁）→ **封顶 7.5**
  - 豁免：含独立监管被侵蚀强信号（药监/科研资助机构/期刊编辑被政治化系列），按生存秩序域秩序观察轴逻辑放行进 ≥8.0，但 reading-log 显式标 `axis: order_observation` 而非 `axis: health`
- hand-wavy mechanism 一票判定 → **≤7.0**
  - 判据：机制解释能套到几乎任何疗法（"减少自身免疫/支持线粒体/血管新生/抗氧化效应"四件套是典型）= 等价喊魔法 = ≤7.0 不进
  - 例：某干细胞疗法文的"机制"解释能套到任何疗法 → hand-wavy 强信号；本应触发 ≤7.0 但当时尚未立此规则故按 8.0 进入
  - 会员的"hand-wavy detector"认知工具经此次伴读已锐化，自动化分身必须沿用此判据

**actionability 硬门**（生命健康域 8.0 准入加一条）：
> 必须能改变会员**今日某条**饮食/训练/睡眠/检测/补充行为。
> "未来某天可能要做的体检"不算今日 actionable；"今天起把蛋白质日摄入提到 ≥1.6g/kg"算。
>
> **⚠️ 决策主体必须是会员本人**：判别问句固定为——**这篇要改变的是【谁】今天的哪个动作？** 答"医生的" → 封顶 7.5，**不因证据质量高而放行**。真 RCT、非劣效设计干净、作者主动列外推边界，都不改变"这是医生手上的决策不是会员手上的"这一点。
> - 实测（某急诊心内科非劣效试验解读文）：真 RCT（437 例，91% vs 94% 落在非劣效边界内，69% 自行转复），作者主动写 "what the trial cannot tell us" + 70% 筛除率的外推边界——**质量没问题**，但"该不该电复律"是急诊/心内科的手 → 7.5 不进池。只看"RCT 一手证据 +0.5"会误抬到 8.0+。
> - 反向验证不误杀：某脂质 panel 解读文决策主体**是会员本人**（改今日读脂质检测的方式），本条不触发，仍按锚定书冗余判 7.5，落点不变。

**实测依据 + 反传**：
- 干细胞疗法文 → 次日反传：当时按 layman 8.0 进入推送，会员反馈"医疗行业长期如此甚至更糟"→ 触发"事后医疗封顶 7.5 + hand-wavy ≤7.0" 双规则；本文复测应是 **6.5-7.0** 不应进推送，但原次推送结果**保留作秩序观察轴**（监管机构弱化反诈警示=独立监管侵蚀强信号 ✅）。复测追加 reading-log `actual_score` 记录。
- 反传至 sources.yaml：功能医学 / 单点大 V 健康博主 / 长寿营销类源故意排除（hand-wavy 重灾区 + 单点信源放大噪音 + 营销重于循证）。

## 怎么用这份示例长出你自己的插件

1. **先跑通用尺子**（`references/scoring.md`）几十篇，把每次「会员打的分 vs 你预判的分」的差记进反馈日志。
2. **等同型偏差出现 ≥2 次**再考虑立一条加权——一次是噪音，两次同型才是这位会员的口味。
3. **每条加权必须带**：方向 + 幅度 + 至少两个实测样本 + 一条可证伪锚（"什么情况下这条不该触发"）。
4. **幅度保守**：宁可 +0.3 不要 +1.0。加权是用来做同质量下的微排序的，不是用来把不合格的顶过门的。
5. **定期回头砍**：本示例的通用部分历史上就砍过好几条——凡是「按标签查表机械扣分」的（命中≠这一篇真有毛病），一律降级为"抓正文时留意"的先验提示，不自动扣分。
