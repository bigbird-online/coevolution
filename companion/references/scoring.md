# 评分规范（companion 步骤1b 逐篇打分）

> SKILL.md 步骤1b 引用本文件。先**预筛分层**挡掉大多数（关⓪），只对"可能过门"的抓正文打两关：先文体封顶（关①）、再内容打分（关②），最终分 = min(文体上限, 内容分)。**封顶在打内容分之前——防自评跑偏**。

## 关⓪ 预筛分层（先批量挡掉 ~70%，别逐篇抓正文——可扩展性命门）

> 实测卡点：47篇（3天+48源）逐篇抓正文已偏重，7天窗口=100+篇必崩。**这一步把算力集中到值得深读的 30%**，否则源/窗口一扩 skill 立刻成瓶颈。

只用**标题 + 源 + 采集器粗筛分**（不抓正文），把候选分三档：

| 档 | 判据（标题/源/粗筛分即可定，不抓正文） | 动作 |
|----|----------------------------------------|------|
| **明确不过门**（约70%） | 标题已是工具发布/版本号/短新闻/数据公告/汇总栏；或源是 avoid 源（如 VC，门槛≥8.5 难达） | 按文体上限**批量压下，不抓正文**，一行记结论 |
| **可能过门**（约25%） | 标题像深度文/调查/独立分析师源，但拿不准 | **抓正文**走关①关② |
| **强候选**（约5%） | trust 源 + 标题直指 focus_domain + 像完整论证 | **抓正文**走关①关②，优先 |

**授权**：明确不过门档**不必抓正文**（实测中评分方"偷工"省掉的正是这一步，现正式授权）。判不准时归"可能过门"抓正文，不赌。

## 关⓪.5 正文完整性 — 前置约束（不是打分时的检查门）

> 经会员三轮追问后的定位修正：完整性**不是 scoring 的一道门**——是**候选进入打分前的前置约束**。
>
> 错误的修法（第一版）："scoring 关⓪.5 = 抓到正文后先过完整性再打分"——本质还是产物层再评，治标。
> 正确的修法：**scoring 的评分对象 = 候选素材本身**；素材不合格 = 候选根本不存在，不会到 scoring 这里。

### 候选的入场资格

scoring 只对**采集层已标 `status: fetched`（且无 `non_full_text_reason`）** 的候选打分。素材层硬约束：

- `article-pool/**/*.md` 头部 `status: non_full_text` → **scoring 不读这类文件**（cron 的 collect_and_score 步骤里就跳过）
- `article-pool/**/*.md` 头部 `non_full_text_reason: <code>` 非空 → 同上

采集层 `scripts/article_collector.py` 的 `detect_non_full_text(url, full_text)` 是入库判定函数（**唯一**判定点），规则：
1. URL 命中已知摘要页（`ssrn.com/abstract=*`、`jstor.org/stable/*`、`papers.nips.cc/paper/*`、`openreview.net/forum?*`）
   - `arxiv.org/abs/*` 单独处理（规则1b）：HTML 页面可能含全文，按字数 + section 标记区分；含 conclusion/appendix/references ≥2 个 **且** word_count ≥ 3000 → 视为全文放行；否则 → `arxiv_abstract_page`（0612 "From Confident Closing to Silent Failure" abs/2606.09863 误杀教训）
2. 付费墙截断 → `paywall_truncation`（0609/0612 Stratechery + 0615 interconnects AGI governance 同源教训，分强/弱信号）
   - **强信号**：含付费墙独有句式即标，不靠字数（`this post is for paid subscribers` / `already a paid subscriber` / `upgrade to paid` / `subscribe to keep reading` / `subscribe to continue reading` / `this article is for subscribers` / `this is a preview` / `members-only content` / `登录后继续阅读` / `订阅后继续阅读` / `付费会员可见` / `付费订阅`）
   - **弱信号**：正文常见词（`subscribe` / `paywall` / `for subscribers` / `log in to read` / `free trial` / `members only` / `premium content` / `付费内容` / `订阅后阅读` / `登录后阅读` 等），需配 word_count < 300 兜底，防止误杀正文里偶提的"订阅"
   - 旧规则只用 word_count < 300 阈值偏低：Substack 免费预览段常 800-1500 字（0615 interconnects 1222 字漏判事故）
3. 正文前 30% 含 defer 链接句式（中英双语：`view pdf` / `read the full paper` / `see full text` / `见原文` / `见 PDF` / `见完整论文`...）
4. 深度文体路径 + word_count < 2000（arxiv / icml / neurips / iclr / position paper / abstract: 前缀）

命中即标 `status: non_full_text` + `non_full_text_reason: <code>` 入库（保留素材便于审计，不删）。

### 为什么不是"产物层再评"

如果在 scoring 层再做一遍完整性检查，等于承认"原料不合格也允许进生产线、产品出来再检"。这条路径有两个问题：
1. **scoring 评分的整套机制（关①文体上限、关②内容分、actionability 软门、三元规则）**全部建立在"采到的就是这篇文章"假设上——一旦假设被打破，整套打分都失效，再加一道"产物自评"也只是补丁
2. **cron 已经在 `content_caveat` 字段诚实标注"只抓到摘要"——还是推了**。说明软标注+产物层评不解决"系统知道但还是放行"的问题；约束必须前置到素材入库

### scoring 兜底审计（仅 audit，不阻断）

打分时若发现候选**理应被采集层 detect_non_full_text 拦下但漏过**，记一条 `audit_caveat` 到 reading-log（不是 content_caveat，那个已废）：
- "采到 X 字，疑似 abstract 漏判"
- "正文含 defer 句式 X，疑似采集层规则缺位"

audit_caveat 触发 → cron 当日紧急 audit（同 1c-iii owner 抓重复机制）+ 改 `detect_non_full_text` 加规则。审计是**反向反传**到采集层，不在 scoring 层补救。

## 关① 文体权重表（对"可能/强候选"档，抓正文判文体、套分数上限）

不同文体内容密度天然不同。判文体**必抓真实正文看**，不靠标题（标题党陷阱）。
**注意付费墙/原文截断**：若正文是付费墙截断/采集残文（实测踩到过：一篇 MIT Sloan 文只采到 611 字），**标记不可靠，不据残文打分**（按截断处保守压分或归"取不到全文"）：

| 文体 | 特征 | 分数上限 | 依据(真实反传样本) |
|------|------|---------|-------------------|
| 深度长文 / 完整论证 | 起承转合、论证推进、有收束 | 不封顶(按内容打) | 基准 |
| 播客摘录 / 精华节选 | 几段独立引文、不推进、无收束 | **≤7.0** | Simon《Vibe coding》实测7.0 |
| 访谈 / 圆桌 / 多人对谈 | 多人轮转、话题跳、问题展不开 | **≤7.0** | 0529 Naval《Vibe Coding Hardware》圆桌7.0 |
| 每周汇总栏 / 链接精选 | 多条导语点到即止 | **≤7.0** | Stratechery《This Week》汇总 |
| 工具发布 / 版本公告 | 版本号、功能点、无认知增量 | **≤6.5** | HuggingFace/Databricks 公告类 |

> 文体上限 ≤7.0/6.5 < 准入门 8.0 → **这些文体默认进不了伴读队列**，哪怕点子不错。
> **表会随反传增长**——新文体踩坑就加一行（底线反传机制，见 SKILL.md 步骤5）。

## 关② 内容分（在文体上限内，按用户 score_baseline 两把尺）

按文章类型分两把尺：
- **策略 / 治理 / 行动方案类**：看 `solution_claim_delivery`——有没有可落地证据（谁做、先做什么、用什么、如何验证、失败风险）。只提质疑/呼吁没交付方法的，压分。
- **洞见 / 趋势 / 认知类**：看是否**说透 + 给新信息量**（把读者隐约感到的东西说透 / 给可检查的判断框架）。

**三元规则**（防回音壁/防虚高）：
1. **命名价值 ≠ 框架价值**：把读者已知现象重新命名/换皮，增量按命名价值计，上限压低。
2. **共鸣 < 证伪**：点头认同不如证伪有信息量。共鸣恰恰可能说明没给新增量。
3. **机构立场不加分**：VC/厂商自我服务的立场背书不计入价值。

**会员先验增量门**（一次重构合并的产物：原「增量价值 #1 确认型 / #3 先行者扣 / 锚定书冗余」三道门本文早已自认三者"同根、五次实测砍的是同一刀"，是同一维度被切成三处重复扣分，累加 -2.0+封顶把真料削到门下，是"名义 8.0 门实际爬到 9 分"的主因之一。合并后**一个维度只扣一次**）：

**核心判断（现场判、一次给分，不累加）**：这篇相对会员的**先验知识 / 亲历经历 / 正在做的实验 / 读过的锚定书**，是**推进**还是**确认**？
- **推进型**（给新框架 / 新事实 / 新判断维度 / 证伪会员自己的判断）→ 不降。
- **确认型**（会员已知 / 已亲历 / 已在做 / 书里已系统覆盖，文章只是给名字或换说法）→ 对该会员增量有限，**一次性封顶 7.5**。

**⚠️不设"轻度确认降 0.5"中间档**（独立复核揪出的减过头口子：私补中间档会让本该重扣的确认型文混过 8.0）。**判不准是推进还是确认时，归推进型、抓正文再看，不赌中间档。**

**判定证据（查这些是为了判"推进 vs 确认"，不是四道独立扣分闸）**：
1. `user/profile.yaml` `member_id` 的已知经历 / 已表态议题
2. `user/profile.yaml` `current_experiments`（会员正在做的反向实验——作者若是旁观者立场谈会员正在突破的事，是最强的"确认型"，因为常识+在突破中=作者立场已被会员工作绕过）
3. `user/feedback-log.jsonl` 过去 30 天会员主动提及的事实/概念
4. **锚定书**（会员系统读过、并且已经进了他自己认知地图的书）——**不手动维护死清单**（会员原话纠过："死清单是熵源"），改为对照会员已有的现成只读源**自动判**。判据是两个条件的交集，不是单一书单：
   - ① 会员的阅读记录里标为"深度阅读"层（不是"翻过/略读"）**∩** ② 会员的知识库/笔记系统里该书确有成体系的节点或笔记 = 确凿锚定书；若笔记系统能给出每本书的笔记条数，条数越高越是这位会员的地基书。
   - **配置方式**：这两个只读源的具体位置因人而异（可能是某个笔记软件的导出、某个 markdown 目录、某个 API），在 `user/profile.yaml` 里指到会员自己的那两处，**产品内核不预设任何路径、不内置任何书单**。
   - 主题落在锚定书系统覆盖内 = 对该会员确认型（"关键证伪"证伪的是大众认知，对已读该书的会员而言证伪的不是他的认知）
5. **会员不走的路径（「花招型增益」子类）**——确认型的另一种形态：不是"会员已知"，是**会员根本不打算走这条路**，因此推进与否都无从谈起。
   - **判据（看主题形态，不看文章质量）**：这条路径是"**把基线做扎实**"，还是"**在既有基线之外找旁路**"？后者 = 花招型增益（hack-type）。健康域的典型形态是桑拿热训练 / 冷暴露 / 单点补剂 / 断食花样 / 特定呼吸法 / 训练变量抠尖；换个域同理——投资域的择时花招、学习域的记忆术、生产力域的工具流花样，都是同一形态。
   - **判定要落在会员自己声明过的基线立场上**。典型的会员表述："我的方法很简单，定时运动，保证总量""我对类似的秘方都不太感兴趣，也不会使用"。会员有这类明确基线立场时 → 该域的花招型主题**封顶 7.5**。**会员没表过态的域不适用本条**，不许替他假设。
   - ⚠️ **证伪豁免的真判据是"会员是否可能撞上"，不是"文章是否在证伪"**：一篇把流行花招证伪掉的文（帮会员省下不该花的注意力）本可走 8.0，但**前提是会员真有可能撞上它**。实测样本：一篇热训练文是干净的证伪型（把"血浆扩张→VO₂max↑"这条链断在最后一环），会员仍只给 7.5，理由是他从未考虑过桑拿这条路——**证伪一个他不会走的路，价值有限**。
   - ⚠️ **防误杀**：本子类只拦"基线之外的旁路"，不碰该域主干。以健康域为例：Zone2 / VO₂max 基线方法论、ApoB 控制、睡眠与前置预防等"把基线做扎实"的主题**不受此限**，仍可走 8.0。
   - **实测两例（同型，独立两次）**：一篇热训练文预判 8.0 → 会员 7.5；一篇增肌训练文预判 8.0 → 会员 7.5（当时归因"健康域抠尖子错配"，实为同一形态）。

**复测三样本（验合并后仍挡得住）**：
- 某胆固醇代谢文：主题落在会员锚定书覆盖内，新发现的受体/U 型曲线只是小增量→确认型→封顶 7.5（与会员实测一致）。
- 某"模型安全寓言"文：会员本人已亲历过同型的模型降级事件=已亲历→确认型→封顶 7.5。
- 某"AI 还没替代软件工程师"文：会员正在做的恰恰是"用多 Agent 分工突破作者所说的三明治"的反向实验，作者是旁观者立场=确认型→封顶 7.5（会员逐字："作者说的是我的常识，没用；我正在做的是突破他说的三明治"）。

三样本合并前分别吃 #1/#3/锚定书三道门累加，合并后各归一次"确认型封顶 7.5"，落点一致但不再重复砍。

**建设性出路检查**（原增量价值 #2，评的是"文章内在逻辑自洽"不是"会员先验"，是独立维度，**保留**）：
- 纯批评无建设性出路 → 内容分 **-0.5**
- 建设性出路与文章自身批评逻辑**自相矛盾**（如"开源解决问题"但批评的就是开源蒸馏）→ 内容分 **-1.0**
- 给出可经检验的建设性出路 → 不降

**论证硬度门**（一次重构合并的产物：原「论证地基质量审查 / 厂商自评 / 供应商工程师自荐审查」三道门本文早已自认"架构同构"，三者都在防同一件事："因为谁说的 / 框架漂亮 / 权威身份，就把信仰当论证给高分"。三道门共 12 个子项全是从**单篇**文章反推出来的，却被拿去套所有同类文，其中"署名人数""有无产品链接""项目命名"是纯形式标签，命中≠真有毛病。合并后**删所有纯形式子项，只留一道现场判意图**）：

**核心判断（现场判、一次给分，不查表累加）**：读完通篇反问——作者的核心断言里，有几步是**论证**（给了可检验的证据/推理），几步是**信仰**（trust me / 因为我是权威 / 框架套着好看 / 用外推冒充证据）？**两步以上是信仰 → 命中，按信仰占比现场定扣 0.5~1.5。**

**信仰的三种典型面孔**（帮识别，不是三个独立扣分项）：
- **外推冒充论证**：用消费叙事/商业必然/历史经验，外推到结构不同的事物（技术进展/监管走向/产业格局），未对照该领域硬证据。（实测样本：某分析师用"这代模型更强→下代必然更强"推演，无视 scaling 已在撞墙的证据）
- **滑坡链 / 叙事拔高**：每步单独看不离谱但累积偏移大，起点终点已非同一事物；或选择性挑对自己有利的叙事剖面（研究机构自家能力报告高发：项目命名指向 X 但 X 没做到、只挑外行基线不挑专家、术语从窄概念悄悄漂移到扩大化结论）。
- **框架感压过硬度**：作者反复用"X 必然 Y"的招牌框架套本篇，是套用不是新分析。

**⚠️ 判别动作：命题方向对味 ≠ 论证硬度过关（同日同向双样本立）**：当一篇文的表层命题正好戳中会员口味（尤其"反权威崇拜 / 反主流共识 / 反建制"这类天然对味某些会员的方向），**必须先数信仰步数再判方向**，不许因命题对味连带给分。机械动作：把作者的核心断言逐条列出，数"几步给了可检验证据、几步是断言"。
- **同日双样本**（同一天、表层命题都是"别把'科学家说的'当真理"，落点差 2.5 分）：
  - 一篇精神外科史书评 → **8.0**：诺奖档案 / 黑猩猩实验 N=2 原始数据被曲解的记录 / 原始专著里 7 例"治愈"有 4 例随访不足 11 天 / 州立医院成本表——每步可查证，信仰步骤 <2。
  - 一篇"别听科学家的"评论 → **5.5**：核心断言（"疫苗致死多于疫病本身""对传播预防零作用""儿童接种零正当性"）零证据链，并以"等当局被迫公布数据"替代举证 = 智识诚实**第一段**失守（隐瞒不利证据），≤6.0。
- **为什么这是最危险的过拟合口子**：尺子里"共鸣<证伪""机构立场不加分""trust 源不豁免"几条，若**只看命题方向**执行，会把"反建制断言文"误认成"证伪文"放行——它们要的是**证伪的硬度**，不是**反主流的姿态**。

**关键精神（保留）**：
- **trust 源 / lab / maintainer 不豁免，反而更警觉**——权威更容易让人放下戒心，分析师本身就是"靠框架感卖订阅"的生意。
- **不是反厂商、反权威**——保留了失败描述的"半诚实"文仍值得读（区别于纯 PR）。反的是**叙事重心选择性偏移 / 信仰冒充论证**，对所有作者一视同仁。
- **删掉的纯形式子项**（不再扣）：三人共同署名、文末挂自家产品链接、项目命名本身——这些"命中标签≠真是广告文/拔高文"，一个诚实好文照样会挂库链接、照样会给项目起名。真信号是"是否规避核心质疑 / 是否选择性偏移剖面"，那是意图判断不是形式清点。

**命中后的诊断动作（帮伴读剥清，不额外扣分）**：厂商/自家产品嫌疑成立时，reason 做「观察 vs 方法论」三段拆分——观察价值（剥掉作者修法/产品，只留可搬开的洞见）、方法论价值（作者押注的那套本身、会员是否真该按这条走）、综合（观察分主导）。剥掉方法论看观察是否独立成立=广告文识别核心动作。

**实测依据**：
- 某分析师评某模型厂商"安全能力"的长文：技术外推+滑坡链+必然论方法论瘾，三步信仰→初评 8.0 拆到 7.0。
- 某机器人研究项目的第二阶段报告：数据真、失败也诚实承认，但"选了对自己最有利的叙事剖面"（命名/基线/术语漂移三段）→会员 7.0，逐字："文章是不是有点哗众取宠"。
- 某开源框架维护者的"够不够 agentic"一文：核心维护者推自家抽象、不论证"这套是否真必要"（信仰冒充论证）→会员 7.0，原话"感觉是个广告文"。合并前吃供应商审查 (a)(b)(c)(d) 四子项凑 -1.0，其中 (a)(b) 是形式分；合并后按"不论证是否必要=信仰"一次现场定扣，落点一致但不清点署名人数/链接。

**为什么不进三元规则**：三元规则评"文章本身"（命名 vs 框架 / 共鸣 vs 证伪 / 机构立场），本门评"作者论证是否硬"——独立维度。

> 评分用**该会员本人的** `score_baseline`（在 `user/profile.yaml`），不用任何全局门。
> 引用外部阅读方法论时**只引用思路、不复制其纪律正文**（复制就把别人的全局判据焊死一遍）。

最终分 = **min(文体上限, 内容分)**。

## 领域插件挂载点（per-member tuning）

> 通用尺子到此为止。**这以下是「因人而异」的部分**——某位会员对文体的偏好、他所在专业域的锚定框架、他反传积累出来的加权，都属于**领域插件**，不属于产品内核。
>
> **产品内核不预设任何加权。** 你的实例从空起，不继承任何前一位会员的口味。
>
> **想知道一份成熟的领域插件长什么样**，读 `references/scoring-profile.example.md`——那是一份**示例**（init 不拷贝它，照抄它是错误用法）。看它的**形态**：一条加权要几个实测样本才够立、怎么写可证伪锚、为什么幅度必须保守。然后去积累你自己会员的那一份。
>
> **挂载方式**：把你自己的加权写在 `user/` 下，在 `user/profile.yaml` 指过去。加权在关② 之后、`min(文体上限, 内容分)` 之前生效。**任何加权都不豁免上面的通用门**——文体上限 / 论证硬度门 / 会员先验增量门 / actionability 硬门 / 触达差价照常全扣，平庸文靠加权顶不过 8.0。

## 对照经典加分/扣分（canonical comparison，反传积累）

伴读时主动比对该领域 canonical work（会员手里已有的认知工具），帮会员定位作者水平相对位置。

**判据**：
- 命中 `user/profile.yaml` `member_id` 已读经典书目（如 selectorate theory 类→《独裁者手册》Bueno de Mesquita；行为经济学类→Kahneman/Thaler；地缘政治类→Mearsheimer/Acemoglu 等）
- 文章主张可被会员手里经典框架解释或证伪
- 显式对照后，按会员判定记录：
  - **作者水平 < 经典**（会员明示"相对 X 水平不高"）→ 不二次扣分（素材分已含），但记 `comparison_anchor` 字段供后续同源文章先验降权
  - **作者水平 ≈ 经典或在经典基础上推进** → 加 0.5（属"推进型"加分，与会员先验增量门不冲突，本规则评的是相对经典的边际增量）

**实测依据**：一篇 Foreign Affairs 的中国经济评论 → 会员明示"相对梅斯奎塔，作者水平似乎不高"。伴读方补做对照时，从会员自己的笔记系统拉出他四年前读《独裁者手册》留下的 25 条原笔记，确认作者归因汇率=症状层 vs 梅斯奎塔致胜联盟=机制层，作者的建议在梅斯奎塔框架下是 not even wrong。该篇 comparison_anchor=The Dictator's Handbook (Bueno de Mesquita 2011)。
> **这一步是本规则真正的机械动作**：不是凭印象说"这作者不如经典"，而是**去会员自己的笔记里把那本经典的原文笔记调出来**，用它当尺去量这一篇。调不出笔记 = 这本书对该会员不构成锚，本规则不触发。

**反传积累**：
- 每次伴读做了对照即记 `comparison_anchor` 字段（feedback-log.jsonl）
- 同 anchor 累积 ≥3 次"作者水平 < 经典" / ≥2 次"≈ 经典或推进" → 记入该作者/源的**先验提示**（"这源历史偏弱/偏强，抓正文时留意"）
- **⚠️不自动扣分（一次降级修正）**：原"累积≥3 次自动先验 -0.3"是按历史标签查表机械扣分，命中≠这一篇真弱（同源作者也可能某篇突然写得好）。降级为**先验提示**：抓正文时留意，但每篇仍按这一篇的真实内容打分，不因"你以前几篇弱"就先扣 0.3。

**为什么独立成段而不并入会员先验增量门**（经独立复核确认）：会员先验增量门评"会员先验 vs 文章增量"（会员认知边界），本段评"作者 vs 该领域 canonical work"（作者水平定位）——两条独立维度，不合并。

## 智识诚实两段检验（expert longform）

评**有立场底色的专家解释性长文**（经济史/宏观评论/地缘政治评论类；区别于给可证伪引擎的"作用层派"——那类作者下的是带验证点的 call）时，除 Actionability 硬门外，加一道两段检验。**判别动作：先找作者立场底色，再定位他在哪句话门口拐了弯。**

- **第一段 = 诚实下限**：他说假话 / 歪曲数据 / 隐瞒不利证据了吗？造假或故意删反方 → 直接压分（≤6.0）。
- **第二段 = motivated reasoning 检验**：他引了反方/雷点之后，是顺着线索往下推到会动摇自己立场的结论，还是立刻拐回安全区？**看见更深真相却因立场不肯落下去 = 第二段失守。**

**判定与封顶**：第一段干净、但第二段失守的文（数据没问题、框架漂亮，却在真相门口拐弯），对**天生不买立场账的会员**（尺子里"共鸣<证伪 / 机构立场背书不加分"那一路口味）增量有限 → **封顶 7.5**，不许靠任何 per-member 加权硬顶过 8.0。
> 反过来说：若某位会员**要的正是立场共鸣**，本检验对他不适用——本条评的是"作者在自己立场门口是否拐了弯"，只有当会员本人认"证伪 > 共鸣"时，这个拐弯才构成扣分理由。

**实测依据**：一篇知名经济史学者关于"中国冲击 2.0"的长文。第一段干净（无造假，且主动引了反方观点："再平衡需要政治优先级根本调头，高度怀疑近期会发生"）；第二段失守——引完这颗雷立刻拐回"欧洲该用何种贸易工具"，看见了"内需才是病根、决策方不愿治"却不落下去。会员逐层证伪（判某国 310 亿股息论据=自满屁股歪 / 引了反方却拐弯=motivated reasoning / 自推终局=捡芝麻丢西瓜的负和飞轮无赢家），自动评分 8.0 → 会员拍 7.5。verdict=`cognition_longform_no_actionability_confirmed_75`。

**与近邻规则的关系**：本规则评"作者诚实第二段是否失守"，对照经典加分评"作者 vs canonical work 水平定位"，Actionability 门评"会员有无可作为空间"——三条独立但常同时命中同一篇解释性长文（上述实测样本三条全中）。

## 自评校准（防系统性偏高）— 是自检不是独立扣分刀

> **本条是被实测打回来重写过的，重写的过程本身就是方法论——请连这段一起读**：
>
> 原版叫「自评校准建议」，讲的是一个实测事实：**评分方的预判系统性地比会员实测高 0.5~1.0**（连续两天分别差 1.0 和 0.5）。这个观察没错。错在它被写成了一条**可以照着扣分的建议**。
>
> 后果：自动化分身把它挪用成"每篇先扣 -0.5（自评校准）保平安"的**无差别全局刀**，与各条具名软门叠加，把 8.5 的真料削到 7.5——这正是连续十一天"一篇都推不出去"里"名义 8.0 门实际爬到 9 分"的元凶。
>
> **教训（这条比规则本身更重要）**：一把**匿名的、说不出扣在哪个维度上的**扣分刀，一定会退化成每篇都套的保险费。**扣分必须具名**——说得出扣的是哪一条，才扣得动。所以**退役这把匿名全局刀**：以下两问是**打分前的自检**（照出偏高倾向），**不产生独立的 -0.5 扣分**。

评 8.0 之前，先在脑里过一遍这两问（自检，非扣分）：

- 这文章会让**会员本人**真**有一个新决定、或一次根本立场再确认**吗？还是只是"我觉得有料"？
- 这文章是**评分者自己想读的**，还是按**会员的尺子**（landing_criteria + score_baseline + 该会员已知的文体与领域偏好）真的能落地的？

**答不出会员怎样落地 → 由具名软门去扣，不再另叠一把匿名 -0.5**：
- 落不了地是因为"文章没给可拿走的东西" → 走 **actionability 硬门**（封顶 7.5）。
- 落不了地是因为"读者自己读摸不到点" → 走 **触达差价**（-0.5~1.0）。
- 落不了地是因为"会员已知该事实/已在做/书里已有" → 走 **会员先验增量门**（确认型封顶 7.5）。

**硬约束（防重复扣分）**：同一"落不了地"的原因**只扣一次**——已被上述某具名软门扣过的，不得再以"自评校准"名义二次扣 0.5。若两问触发的偏高**无任何具名软门可归因**（纯粹"打分者手感虚高"、说不出具体哪个维度不适配），才在打分时对该篇标 `self_calibration_flag` 并 -0.5，且**reading-log 必须记明"无具名软门可归因"**——不许再默认每篇套。

## 供应商工程师自荐审查（vendor audit）→ 已并入「论证硬度门」

> 原独立门（由某开源框架维护者的自荐文立，四子项 (a)(b)(c)(d) 封顶 -1.0）与「论证地基质量审查」「厂商自评」架构同构（本文自认），三门已合并为一道**论证硬度门**（见关② 内）。这段墓碑保留，是为了让后人知道**这三道门为什么被合并、删掉的是哪一类子项**——不知道这个，很容易再把纯形式子项加回来。
> - **删掉的纯形式子项**：(a) 三人共同署名、(b) 文末挂产品链接——这两条清点的是署名人数/有无链接，命中≠真是广告文（诚实好文照样挂库链接），是过拟合标签，删。
> - **保留的意图子项**：(c) 承认失败放边角不撼核心、(d) 不论证"是否真需要这套"直接默认前提为真——这两条是"信仰冒充论证"的真信号，并入论证硬度门"信仰的三种面孔"里现场判。
> - **命中后的观察 vs 方法论三段拆分**：保留为诊断动作（帮伴读剥清），见论证硬度门"命中后的诊断动作"。

## takeaway 受众分类（防 Agent 自利灌水）

> **为什么需要这道尺**：当打分方本身是个 AI 时，它会不自觉地把"这个我用得上"当成"这个会员用得上"。takeaway 一旦不标受众，自利条目就会混进 actionability 计数里把分抬起来。这是自动化评分特有的一种系统性虚高。

自动评分的 reason 用 "N 类直接 takeaway" 列点累积加分时，**每条 takeaway 必须显式标受众**：

- **会员可用**：会员真会拿去做决定/改行为/校准认知的
- **Agent 自利**：打分方自己想用的（拿去改自己的评分尺、评估自家工具改动、给内部调度做参考等）

**只有"会员可用"类计入 actionability 分**。Agent 自利类不算 actionability（属内部改进素材，价值另算）。

**反例诊断**：某开源框架维护者的文章，自动评分列了 4 类 takeaway 给 8.0，其中两条（"这个测法可以拿去改我自己的评分尺""这个采纳率指标可以拿去评估自家工具改动"）是 Agent 自利不是会员可用；真正会员可用的只有 1 条测量学观察 + 半条方法思路（会员可参考但非直用）。**4 条灌水成"actionability 强" = 系统性抬分**，扣除自利类后 actionability 实际只 1.5 条 = 8.0 准入不够稳。

**⚠️ 前置判断：判"Agent 自利"前先问"主题是否讲 AI 产物/AI 协作本身"（防把该算会员可用的误归自利）**：

**若会员本人是 AI 重度使用者、每天要为大量 AI 产物的真假负责**，那么一篇讲"如何判 AI 输出好坏 / 如何让 AI 产物可被验证"的文章，对他**天然是"会员可用"**，不因为它举的例子是工程师就归到 Agent 自利。判受众看的是**读者能否拿走那把尺**，不是文章拿谁当例子。

- **反例（本条触发案例）**：一篇《难以评测=产品坏味道》，自动评分判 7.8，理由是"这个框架可以迁移到我们造 Agent 的判据上 = Agent 自利，非会员可用"。**误在把读者身份默认切成了"产品工程师"**——文章命题是写给"任何要为 AI 输出负责的人"的，其中工伤报告的案例（医生拿到 50 页 AI 报告，要信就得重读整本病历=等于白给）正是这位会员的每日处境。会员人工越门后，伴读当场用"和我写实验笔记一样"把它收编进自己的框架，证实它给了会员一把可拿走的验证尺。
- **下次行为变化**：评一篇 AI 主题文时，若拟给某 takeaway 标 "Agent 自利"，先自检——**这把尺是"只有造 Agent 的人能用"，还是"任何被 AI 产物轰炸、要判真假的人都能用"？** 后者一律标"会员可用"计入 actionability。**"文章举工程师例子" ≠ "受众是工程师"。**
- **反过来也成立**：若会员并不与 AI 产物打交道，同一篇文章对他就真是"与我无关"——本条的判据是**会员的实际处境**（写在 `user/profile.yaml`），不是文章的主题标签。
- **⚠️ 二次校准（同日会员拍 7.5 后，纠本条自身的矫枉过正）**：本条撤销"Agent 自利"误诊 = 对（读者身份别切窄），但**不等于此篇过 8.0**。会员当场拍 **7.5**，原话"不容易读，高级外行可能看不到点上"——真扣分点是**高级外行触达差价**（见下方独立规则），不在受众分类这把尺内。教训：证明"跟会员有关"≠"抬过 8.0 门"；**撤销一个误扣时不要顺势矫枉过正把分抬过头**。此篇正确判分链 = base 高 → 撤 Agent-自利误扣 → **但卡触达差价 → 7.5**。

## 高级外行触达差价（由一次"内行读 8+、会员只给 7.5"的实测立）

**一篇内在价值高、但藏在内行语境里的文章，对"高级外行"读者的真实价值要按触达打折。**

- **高级外行 = 懂行、有判断力，但不是这篇所属那一行的从业者**（绝大多数会员对绝大多数专业子领域都是此位）。
- **触发条件（后经一次复核收窄 + 加可证伪锚）**：不是"裹在专业外壳里就扣"——那是深度的代价，会对所有深文误征一笔"深度税"。只有**普适道理本可平实说、作者却无必要地锁进行话，高级外行穿不过**才扣。扣前必须能答出以下机械锚**至少一条**，否则不扣：
  - ① **同一道理在本领域外也成立、却被作者无必要地锁进本行话**——不限某一个域，各域同吃：
    - 技术域例："信任该逐步攒不该一锤子买卖"是普适的道理，却只用某个工程工具链的语境讲；
    - 法律/宪政/史/哲学域例：一篇宪政史长文的底层点是"权力制衡该由谁说了算"（普适），却堆在判例名 / 机构缩写 / 法院代际的专有名词墙后面，高级外行穿不过（**法律长文的行话墙 = 判例名与机构缩写堆叠，与技术文的术语墙同型**）；
  - ② **存在平实改写版**：能把核心点用高级外行不靠专业背景就懂的话复述出来。**判定动作：扣分前先试着做这个平实改写——改写得出 = 道理确实被行话墙挡了，该扣；改写不出 = 点本身就依赖专业深度（那不是触达问题，是内容问题、由 actionability/内容分管），不扣。**
- **扣分**：内行读值 8+，但高级外行剥不出点（且过了上面锚）→ 折 **0.5~1.0**，落 7.0~7.5。**扣的是文章与读者之间的"距离"，不是文章内在质量**（区别于文体上限/内容分/actionability 那几把评内在质量的尺）。
- **与 specialist/layman 双窗打分一致**：一篇 scaling laws 综述 specialist 8.5 / layman 7.0（-1.5）就是这一刀；本规则把它从"可读性兜底"提为**独立降分门**，不限某个域、不限某个来源，各类深文同吃。
- **豁免**：有伴读当场把点剥出来时不折（伴读=补上触达）。但**无伴读的纯推送场景，触达差价必扣**——因为会员是自己读。

**反例（本条触发）**：一篇《难以评测=产品坏味道》——内行读 8+（溯源 / 可验的最小单元 / 三个案例都是好尺），但会员原话"不容易读，高级外行看不到点上"：道理裹在工程语境（笔记本单元格 / 评测流程 / 三个工程产品案例）里，高级外行穿不过工程外壳去摸底层那句"信任该攒不该一锤子买卖"。**纯推送场景 → 触达差价 -0.5~1.0 → 7.5**。当天是有伴读把点剥出来了，但那不改纯推送场景的判分。

**下次行为变化**：评内行语境深文时，除内在质量三把尺外，加一道自检——**"高级外行自己读，能不能不靠伴读就摸到那个点？"** 摸不到就按触达差价折 0.5~1.0，落 7.0~7.5，不硬顶 8.0。

### 无伴读场景挣豁免的路径

> **门文本一字不动**（上面 -0.5~1.0 的扣分逻辑全保留）。本路径不是"降门"，是**合法命中条文自带的豁免钩**——豁免钩原文写「有伴读把点剥出来时不折（伴读=补上触达）」，而必扣的前提是「无伴读、纯推送」。**把推送形态从"纯推送原文"升级为"附翻译 + 剥点材料"，触达就被真补上，它不再是"纯推送"，豁免钩合法激活。**
>
> 这是一个值得记住的通用手法：**与其为了让候选过门去松门槛，不如去满足门自带的豁免条件**。前者是尺子退化，后者是真把问题解决了。

**触发**：某候选内在质量 ≥8.0（三把内在尺全过），**仅**卡在触达差价 -0.5~1.0 落到 7.0~7.5（不是卡 actionability / 文体 / 内容分——那些是文章里没有的东西，翻译剥不出来，见下方红线）。

**挣豁免的动作**（推送时当场做，非事后补）：为该候选产出「剥点材料」——把裹在专业外壳里的普适道理，翻译成高级外行不靠专业背景也能穿透的表述（术语解释 + 一句话"这文对你意味着什么" + 剥出的可拿走的点）。剥点材料随推送一并送达 = 触达被真补上。

**过门判定**：剥点材料产出后，该篇触达差价折扣**豁免**（回到 ≥8.0），进伴读队列正常推送。**豁免钩挂在"触达真被补上"这个逐篇的产物属性上**——判的是"这一篇的剥点材料是否真把点剥出来了"，由复核判定。

**三条红线（防退化成"贴个标签就放行"）**：
1. **不钩作者身份**：豁免只认"这篇有没有真剥出点"，不认"作者是不是名家"。名家文一样要真产出合格剥点材料才豁免——只凭身份放行，与「per-member 加权不得当过门器」是同一种病（**身份不是过门器**）。
2. **只救触达差价，不救 actionability**：actionability 卡的是"文章里根本没有可拿走的东西"，翻译和剥点**造不出文章里没有的落点**（这一条被独立复核驳回过、被会员五次以上实测确认过，另有"伴读发散但无落点=没用"只给 7 分的先例）。仅卡 actionability 的候选**维持 7.5 封顶，不走本路径**。
3. **剥点材料质量不达标 = 豁免不激活**：剥点材料若只是原文摘要 / 翻译腔堆砌 / 没真穿透外壳，触达就没被补上，折扣照扣落回 7.5。剥点合格与否由**独立复核**判（**不能自评**），reading-log 记录哪篇靠哪份剥点材料挣到豁免（`reach_gap_exemption: {material_id, verified_by}`），供运营者事后抽查有没有误放。

## takeaway 受众分类（续）

**reason 模板要求**：
```yaml
takeaway:
  - {audience: "会员可用", desc: "..."}
  - {audience: "Agent 自利", desc: "..."}  # 不计 actionability
actionability_score: <只数会员可用条数>
```

## 准入与门槛（步骤1c）

- **≥8.0 才进伴读队列**。
- 队列空怎么办：扩时间窗重采 / 触发扩源信号（见底线反传）/ 诚实输出"本窗口无合格候选"。**不降标准硬凑。**
- 另有两条落盘门（区别于上面的伴读队列门）：会员精选池 ≥7.5；命题级信号 ≥8.0 且需双确认。反馈回传**每篇必做**（见 SKILL.md 步骤5 底线反传）。

## arXiv 来源提示（原「+0.5 高星硬门」已删——这是一条"用标签代替判断"的典型病例）

> 原门对 source 含 "arxiv" 就把准入门从 8.0 抬到 8.5（除非命中一份写死的机构白名单），是**用来源前缀标签代替质量判断**——arXiv 只是**载体**不是质量信号，里面既有顶会档强工作也有练手投递，一刀切 +0.5 惩罚整个来源会误杀独立研究者的扎实文（要 8.5 才过，比同质量博客文凭空高半档门）。
> **这条病例值得推广到任何来源**：只要你发现自己在按"来源前缀 / 机构名 / 平台"调门槛，就该停下来问——真正想挡的是什么？那个东西有没有一道具名的门在挡？有，就删掉这条来源税。

**改法**：**arXiv 不再单设抬高的准入门**，同一套判断力尺子（文体上限 / 论证硬度门 / actionability 硬门 / 会员先验增量门）照常跑，通用 8.0 门即可。
- 防"练手投递混进来"靠 **actionability 硬门 + 论证硬度门**（练手投递要么没可拿走的落点、要么论证是信仰）——这些门本就在挡，不需对整个来源再征 0.5 的税。
- **trust 白名单降为先验提示**（不降门）：命中 `arxiv_trust_affiliations` / 历史高分作者 → 只作为抓正文时"这源大概率靠谱"的先验，但仍按这一篇真实内容打分，不因机构名就先加分或降门。
- **复测验证落点一致**：一篇会员实测 7.0 的 arXiv 文，在新尺子下卡的是"会员从未亲历文中所述现象=对他增量有限"（会员先验增量门）+ 论证靠框架感（论证硬度门），不靠"arxiv +0.5"这道来源税也能落到 7.0~7.5，落点一致。**删掉一道门之后必须做这种复测**——证明原来被它挡住的东西，现在仍被别的具名门挡着。

## Actionability 门（8.0 准入必过）

7.5 → 8.0 之间有一道 **actionability 硬门**，比文体/内容/相关性更上游：

**事实/洞见再扎实，如果对"个体读者出去后能多做什么、少做什么、新增什么判断框架"没有 actionability，只能停在 7.5——算"有用但没大用"。**

8.0 必须满足之一：
- 给出读完后**可改变行为**的东西
- 给出**可拿走用的判断框架/决策模型**
- 给出**可复制的做法**
- 给出**对既有判断的关键证伪**

**不算 actionability**（默认压在 7.5）：
- 政策呼吁、学术建议（对个体无 takeaway）
- 纯事实陈述（"知道了" ≠ "有大用"）
- 价值落点错配（事实在 X 层，用户瓶颈在 Y 层，文章帮不到瓶颈）

**实测依据**：
- 一篇《用 AI 把代码写得更好、更慢》→ 7.5。价值落点错配：方法学交付清晰，但该会员的瓶颈在"沉心做事"这个 AI 加速不了的层面。
- 一篇关于家政工重疾保障的深度调查 → 7.5。事实扎实、写法克制，但对个体读者只是"知道了"、无 takeaway，只能进精选池不进事件级信号池。

> **注意"价值落点错配"这一条是相对会员的**：同一篇文章，换个瓶颈在别处的会员就可能是 8.0。actionability 的判据永远是"**这位**会员出去后能多做什么"，不是"文章有没有给出行动建议"。

## 领域子规则挂载点（domain sub-rules）

> 某些会员在某个专业域里有**一套自己认的框架**（一本系统读过的著作、一套预防医学范式、一套投资纪律），该域的文章要用那套框架当锚去打分。这类规则**整段属于领域插件，不属于产品内核**。
>
> 产品内核**不预置任何领域子规则**——不预设你的会员关心健康还是关心宏观，更不预设他认哪一派。
>
> **示例见 `references/scoring-profile.example.md` 第二节**（一份以某本长寿医学著作为锚的健康域子规则）。读它是为了看**一份领域子规则该包含哪几件东西**：
> 1. **触发条件**（什么样的候选进这套子规则）
> 2. **锚结构**（该域的判断骨架，用来判"命中了没有"）
> 3. **加分点 + 封顶判定**（含"一票判定"式的硬否决，如"机制解释能套到任何疗法 = 等于喊魔法"）
> 4. **该域专属的 actionability 硬门**（含**决策主体是谁**的判别问句——这条最容易漏：证据质量再高，若这是专业人士手上的决策而非会员手上的，仍不算 actionable）
> 5. **实测依据 + 反传**（哪次实测把这条逼出来的、反传改了哪些源）
>
> **照抄示例里的健康观 = 错误用法。** 要抄就抄这五件套的结构。
